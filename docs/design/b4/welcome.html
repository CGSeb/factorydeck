Install the factory in a project

FactoryDeck shows the projects that use the factorydeck-skills workflow. None of yours does yet.

  1. 1 Install factorydeck-skills in your coding agent: see the install steps.
  2. 2 In your project, run /setup-factory. It writes docs/agents/factory.yml.
  3. 3 Work in that project with your coding agent. FactoryDeck finds it at its next ingestion, earlier sessions included.

The project select appears once a project has sessions.
